**Router-kill** es un framework diseñado para automatizar distintos métodos de ataque contra routers. Actualmente, muchas redes Wi-Fi continúan siendo vulnerables a este tipo de ataques, y este programa desarrollado en BASH facilita su ejecución mediante la automatización de procesos. Funciona principalmente apoyándose en dependencias ampliamente utilizadas en distribuciones especializadas como Kali Linux y Parrot Security OS.

**Router-kill** is a framework designed to automate various methods for attacking routers. Currently, many Wi-Fi networks remain vulnerable to these types of attacks, and this program, developed in BASH, helps streamline their execution through process automation. It primarily relies on well-known dependencies commonly used in specialized distributions such as Kali Linux and Parrot Security OS.


## Tipos de Ataques

| Ataque        |   Informacion                                 |
|---------------|-----------------------------------------------| 
| Deauth:       | Desauntentica todos los clientes de la red    |
| Auth          | Solicita y manda solicitudes falsas de Auth   |
| Fake AP       | Crea un flood de Falsos puntos de acceso      |
| Inject packet | Autentica un falso cliente y Inyecta paquetes |
| Handshaske    | Captura el Handshake de la red solicitada     |
